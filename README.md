# EnglishU Reel kit (Remotion)

A code-only kit that reproduces the paper-collage look of `reference/plane-reel.mp4`
for every EnglishU Reel (1080x1920, 30 fps). No image/video generation services are used:
every texture, strip, cloud and crystal is generated by the Python scripts in `/tools`.

* `reference/STYLE.md` is the source of truth for the look (sampled palette, typography, motion).
* `renders/` has the latest check of the test composition: `contact_sheet.jpg` (one still every 0.5 s),
  `frame_light_84.png`, `frame_dark_190.png` and `TestLook.mp4`.

## Start

```bash
npm install
```

```bash
npm run studio
```

Studio opens at http://localhost:3000. Pick **TestLook** or **Template**. Every element has
`x`, `y`, `scale` and `rotate` in the right-hand props panel; tweak them and press **Save** to
write the new values back into `src/Root.tsx`.

Render:

```bash
npx remotion render TestLook out/TestLook.mp4
```

If the render browser has no internet (it times out on "Fetching ... font"), use the local copies
of the same Google Fonts:

```bash
node scripts/fetch-fonts.mjs
```

```bash
REMOTION_LOCAL_FONTS=1 npx remotion render TestLook out/TestLook.mp4
```

## Make a new Reel

1. **Copy the template:** duplicate `src/reels/_Template` to `src/reels/<ReelName>` and register it
   in `src/Root.tsx` (copy the `Template` `<Composition>` block, change `id`, `component`,
   `durationInFrames`). Keep each scene in its own file (`Scene01Hook.tsx`, `Scene02Word.tsx`, …)
   and all beats in that folder's `timing.ts`.
2. **Set the theme (one world, one palette):** copy `src/kit/themes/plane.json` to
   `src/kit/themes/<topic>.json`, change `name` and the colours (light base, dark base, paper,
   accent …), add it to `themes` in `src/kit/theme.ts`, then build the world assets:
   ```bash
   cd tools && pip install -r requirements.txt
   ```
   ```bash
   python make_plate.py --palette <topic> --theme light && python make_plate.py --palette <topic> --theme dark && python make_plate.py --palette <topic> --theme paper && python make_plate.py --palette <topic> --theme pale
   ```
   ```bash
   python make_props.py all --palette <topic>
   ```
   Set `theme: '<topic>'` in the composition's props.
3. **Cutouts:** put photos anywhere (e.g. `tools/sources/`, note the license in `tools/sources/SOURCES.md`) and run
   ```bash
   python tools/make_cutout.py tools/sources/photo.jpg --model u2net
   ```
   The PNG lands in `public/assets/cutouts/` (white paper border + shadow baked in). Use it with
   `<Cutout src={asset('cutouts/photo.png')} …/>`. Torn strips: `python tools/make_torn.py --help`.
4. **Voiceover:** put her recording in `/public` (e.g. `public/voiceover.mp3`) and set the
   `voiceover` prop to the file name. Retime `timing.ts` to the voice.
5. **Subtitles:** set the `subtitles` prop: `[{text, from, to}]` in frames. English words inside
   Hebrew lines are kept left-to-right automatically.
6. **End card:** replace the placeholder `public/endcard.png` with the real one and set
   `endCard: true` (it plays for the last 2.7 s; make the composition 2.7 s longer).

## Rules

* **One world per Reel**, one locked plate, one slow camera push (1.0 → ~1.06). Change world only
  with `<TornWipe>` into `<WorldLayer variant="dark">`, never a hard cut.
* **About 90 Hebrew words maximum, one fact.**
* **Topic-driven palette:** 3-4 colours + ONE accent. The accent is only for the key word half,
  one swoosh, and arrows.
* Never use brand navy `#0A2370` or brand red `#B01F25` in the body (logo and end card only).
  No red marker circles, no flat colour fields, no clean rectangles.
* Every image is a cutout with a white paper border and a shadow, rotated within ±4°.
* Keep the bottom fifth (y > 1536) and the right ~130 px clear of important content
  (`SAFE` in `src/kit/Subtitles.tsx`).
* Motion: `spring` pop-ins (damping ~12), `interpolate` for pushes/pans/fades, entrances 4-6 frames
  apart, never everything moving at once.

## Layout

```
reference/          plane-reel.mp4, extracted frames, STYLE.md (source of truth)
tools/              Python generators (paperlib.py shared maths)
  make_plate.py       crumpled paper plates (light / dark / paper / pale), halftone patches
  make_torn.py        torn strips and edges (PNG) + SVG clipPath export
  make_cutout.py      photo -> B&W cutout with irregular white border + shadow
  make_props.py       paper clouds, hexagon crystals, tileable grain
public/assets/      generated assets (worlds/<theme>/…, torn/, cutouts/, grain.png)
src/kit/            the kit: World, WorldLayer, TornWipe, Cutout, TornStrip, PaperCloud,
                    Crystal, PaperLabel, KeyWord, Swoosh, Arrows, Subtitles, EndCard,
                    theme.ts + themes/*.json, torn.ts (SVG clip-path generator), paths.ts
src/reels/TestLook/ the 7 s look test (one file per scene)
src/reels/_Template copy this to start a Reel
src/reels/Smallpox/ the smallpox Reel (ERADICATE + OUTBREAK): SCRIPT.md, timing.ts, one file per scene,
                    paper.tsx = paper-craft pieces drawn in code (arm, cow, outbreak blob, rings)
```

## Smallpox Reel

```bash
REMOTION_LOCAL_FONTS=1 npx remotion render Smallpox out/Smallpox.mp4 --concurrency=1
```

`--concurrency=1` matters on small machines (the SVG paper filters are heavy). Script, beat map and the
retiming steps are in `src/reels/Smallpox/SCRIPT.md`. Its world is `src/kit/themes/smallpox.json`
(sage paper, bottle-green dark paper, cream, one coral accent); assets were built with
`make_plate.py` / `make_props.py --palette smallpox`.
